# 4-3.4 Verification And Durable Docs

## Verification

A valid result cites a concrete control-plane capture or a reproducible deployed request/redirect/header trace.
A source file, environment-name convention, proxy test, or stale durable document is insufficient for a runtime
fact.

## Durable Docs

No durable change is planned by default. Promote a deployment/callback rule only after the observed fact is stable,
has a clear owner, and changes the generative architecture rather than merely recording a current hostname.
