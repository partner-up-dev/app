# 4-3.4 Rehearsal

If the provider console confirms the expected API domain and the edge redirect chain matches it, a later packet
may consider topology hardening with controlled-browser proof. If the console shows a legacy callback consumer or
a different authority, that consumer remains supported and a separate compatibility migration is designed.

If public endpoints are unavailable from the current environment, record that as an observational limitation. It
does not change the local result semantics or justify a fabricated successful probe.
