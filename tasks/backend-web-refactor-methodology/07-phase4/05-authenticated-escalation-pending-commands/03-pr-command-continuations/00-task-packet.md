# 4-4.3 PR Command Continuations

Own the five named PR continuation writers and handlers: join, waitlist, exit, confirm, publish. Do not make create,
cancel, check-in, content/status, join-gate, messages, feedback, POI, or Commerce actions replayable.

## Result

Complete. The five named writers persist their existing intent before claiming the exact authenticated-required
response. Waitlist carries its checkbox value only into its resumed gate; no non-named command became replayable.
