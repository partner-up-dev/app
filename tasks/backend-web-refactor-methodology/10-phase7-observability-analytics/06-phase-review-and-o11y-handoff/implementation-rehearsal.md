1. Assemble slice evidence without first rerunning broad gates.
2. Audit rejected mechanisms and authority arrows.
3. Audit deployment/config/docs consistency.
4. Audit Registry/fact/Web owner boundaries.
5. Run canonical full gates once.
6. Promote durable truth.
7. Create the future O11y requirement packet only when that task is explicitly
   opened; do not pre-create implementation files here.

## Branches

- External SLS access unavailable: record local completion plus exact external
  blocker.
- Canonical gate encounters unrelated work: isolate the scoped revision and
  report, never absorb it.
- Operation-log retention remains unresolved: carry it explicitly; do not
  claim complete retirement.
- A metric lacks product meaning: exclude it from completion claims.
- A future requirement tempts an implementation choice: record the question
  and constraint, not a solution.

## Stop Conditions

- Any rejected adapter/query/debug path remains locally without disposition.
- Any telemetry becomes authority.
- Any production BI reader parses raw payload.
- Durable docs call the clean baseline “implemented observability”.
