# Structural Target Metrics

## Role Of These Metrics

These metrics are necessary structural signals, but they are no longer Phase exit claims by themselves. A reduction
only counts when the affected fact has one named writer, an explicit temporal trigger/reconciliation path, a
non-authoritative read/cache projection, and coherent vocabulary. `C0` owns that proof.

| Controller consumers of wildcard roots | 4 | 0 after `5-6A` | Controllers consume explicit category entrypoints. |

| Admin repository-composition consumers | 15 files | no growth; not closed in this Phase | A future Admin read-contract design owns this number. |

The row counts are inventories, not substitute evidence. Each reduction must be remeasured at the owning slice exit.

## Explicit Non-Metrics

- total lines in `create-order.ts`, `useCommerce.ts`, or provider adapters;
- number of files/directories created or deleted;
- number of bugs closed;
- number of services/controllers changed in one patch;
- total import count without owner/category classification.

These can be diagnostic clues but are not architecture outcomes.
