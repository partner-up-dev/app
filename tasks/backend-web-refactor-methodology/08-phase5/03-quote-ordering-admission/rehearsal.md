# 5-2 Rehearsal

| Input branch | Expected outcome | Abort condition |
| --- | --- | --- |
| creator, eligible PR, fresh quote | create one PR-attached order | any copied browser fact reaches create command |
| creator, expired quote | refresh listing; require a second explicit create | automatic retry or stale candidate resurrection |
| participant with existing non-terminal order | route to existing Order Detail | new order starts |
| non-creator with no order | follow D1, never reach an inevitable server rejection | page invents a different order authority |
| unpaid eligible participant | focused blocker/dialog path | payment/settlement logic is duplicated in Web |

If a branch needs a new product rule rather than an implementation owner, stop and return to the PRD.
