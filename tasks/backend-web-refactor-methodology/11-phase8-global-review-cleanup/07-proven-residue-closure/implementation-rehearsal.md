# `8-6` Implementation Rehearsal

## Decision Procedure Per Residue

1. Name the owner and current consumers, including dynamic/config references.
2. State the behavior or compatibility obligation.
3. Prove the replacement already exists or implement the smallest owned seam.
4. Remove the old path only after focused and cross-unit proof.
5. Otherwise retain it with a concrete external/future exit condition.

## Important Branches

- **A Knip-unused file is linked from `AGENTS.md` or docs:** it is not
  reference-free; replace the instruction/reference deliberately.
- **A direct RPC is part of OAuth terminal compatibility:** retain the named
  exception.
- **A one-line re-export has no imports but is a documented package path:** keep
  until the contract path is explicitly retired.
- **A Job column is read only by legacy normalization:** Sir's cut-off decision
  removes old-client/old-job product concern, but schema/runtime reader removal
  still needs forward-migration and current-fixture proof.
- **The CaoCao legacy callback may be provider configured:** external evidence,
  not local deletion.
- **Historical task prose disagrees with current Git:** update the current
  index and add a historical annotation; do not rewrite the old event.
- **The external proof needs logging:** use operator edge/network evidence; do
  not restore console or structured-output diagnostics.
