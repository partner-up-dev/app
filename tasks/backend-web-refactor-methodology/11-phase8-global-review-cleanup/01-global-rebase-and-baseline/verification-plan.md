# `8-0` Verification Plan

## Delegation Value

Each auditor owns a disjoint source plane and returns evidence only. Root does
not repeat whole-codebase exploration; it validates with:

1. cited-path existence;
2. deterministic reporter/count reruns;
3. a small source sample for every high-priority family;
4. cross-plane authority conflict checks; and
5. final worktree/link/whitespace inspection.

## Read-only Commands

- architecture fitness reporter and reviewed-baseline classification;
- scoped source/file/LOC/import/route/transport searches;
- report-first `check:dead-code` and `check:security` when their current
  execution does not require mutation;
- Git history/blame for disputed status or implementation provenance; and
- Markdown relative-link validation.

Full tests/builds are not repeated merely to rediscover Phase 7's just-recorded
green baseline. `8-0` names the final Phase 8 gate matrix instead. Executed
evidence and root sampling are recorded in
[`verification-log.md`](./verification-log.md).
