# `6-4c` Mental Rehearsal

- Provider accepts then response drops: generic retry may call again; the
  duplicate-effect risk is explicitly accepted.
- Process dies during provider I/O: lease recovery uses ordinary Job mechanics;
  no RideHailing `UNKNOWN` state is introduced.
- Payload contains an allowance amount: reject the design; the current official
  contract permits omission and the product owns no subsidy decision.
- Handler adds an unconditional order-detail fetch: reject it unless a separate
  product or recovery requirement justifies the extra dependency.
